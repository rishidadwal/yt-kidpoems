# Privacy Policy – KidPoems

KidPoems is a personal, automated tool that makes original children's poem videos and uploads them to the
owner's own YouTube channel. It is not offered to other users.

**What it accesses.** With the channel owner's permission (Google OAuth), it uses the YouTube Data API only to
upload videos and thumbnails to that owner's channel and to set their details (title, description,
"made for kids"). It does not read, collect or store data about viewers, children or any other person.

**What it stores.** Nothing personal. Access tokens are kept only as encrypted GitHub Actions secrets and are
never written to files or shared.

**Children.** Videos are marked "made for kids" on YouTube. The tool collects no information from children.

**Revoking access.** The owner can remove access at any time at https://myaccount.google.com/permissions.

**Contact.** Open an issue at https://github.com/rishidadwal/yt-kidpoems/issues.

YouTube's terms: https://www.youtube.com/t/terms · Google's privacy policy: https://policies.google.com/privacy
